원문을 한국어로 옮긴 참고용 번역입니다. 장비명·모델명·수치는 원문 그대로 두었습니다. 해석이 갈리는 곳은 원본을 기준으로 합니다.

기술 요구사항 — 사운드 Technical Requirement — [ sound ]

항목사양 / 내용
PA 2.1ch 시스템 [ 스테레오 + 서브우퍼 ]PA 2.1ch system [ Stereo + Subwoofer ]
메인 PA 2ch예: Meyer Sound M’elodie 커빌리니어 어레이 라우드스피커
주파수 응답: 60Hz - 20kHz
베이스/서브우퍼예: Meyer Sound 700-HP
주파수 범위: 30Hz - 120Hz
총 허용 출력: 공연장 규모에 따라 결정.
공연장 규모에 맞는, 탄탄한 저역 응답(30 Hz – 120 Hz)을 제공하는 충분한 서브우퍼 시스템이 필요합니다.
무대 위 믹싱 콘솔 * 1예: Mackie 1642VLZ4
입력 채널: 6 (최소) / 밸런스드
출력 채널: 3 (최소)
2ch 메인 아웃 + 1ch 독립 라인 출력(예: Sub Outs, Group Outs). AUX Send는 사용하지 않음.
오디오 케이블 * 6오디오 인터페이스(RME Fireface UCX II, 1/4” TRS 잭, 밸런스드)에서 믹싱 콘솔까지
롱 오디오 케이블 * 3무대 위 믹싱 콘솔에서 PA까지

* 노트북(Apple MacBook Pro)과 오디오 인터페이스(RME Fireface UCX II)는 작가가 직접 지참합니다.

기술 요구사항 — 영상 [ video ]

항목사양 / 내용
비디오 프로젝터 * 2해상도: WUXGA [ 1920 * 1200 pixels ] (최소)
화면비: 16:10 네이티브
밝기: 10000 lm (최소)
16:10 스크린 * 2크기: 예) 각 8000*5000 mm
* 최소 크기: 각 4000(w) * 2500(h) mm
2개의 독립된 스크린을 서로 간격(10-80cm)을 두고 설치
일직선 또는 V자 형태로 셋업
롱 비디오 신호 라인 * 2소스에서 프로젝터까지
모든 구성 요소(케이블, 익스텐더, 컨버터)는 WUXGA를 지원해야 합니다. EDID 패스스루가 가능한 네이티브 WUXGA 지원 익스텐더, 또는 고대역폭 전송 시스템(예: 광케이블 전송, HDBaseT)을 사용해야 합니다.
* 3G-SDI 전송 시스템은 Full HD까지만 지원하므로 네이티브 WUXGA를 전송할 수 없습니다.

테크니컬 셋업 (연결도) Technical Setup

원문의 연결 다이어그램에 표기된 내용을 신호 흐름 순서로 옮겼습니다.

무대 테이블 위 On the stage table

  • Apple MacBook Pro → USB 케이블(USB-C) → 오디오 인터페이스 RME UCX II
  • Apple MacBook Pro → 비디오 케이블(HDMI) → HDMI 출력: WUXGA (1920 * 1200) → 프로젝터 1
  • Apple MacBook Pro → USB-C - HDMI 어댑터 → HDMI 출력: WUXGA (1920 * 1200) → 비디오 케이블 → 프로젝터 2
  • RME UCX II → 밸런스드 라인 오디오 케이블 6개 → 믹싱 콘솔 (6ch을 2.1ch으로)
  • 믹싱 콘솔 → 오디오 케이블 3개 → PA: 2.1ch (3ch - 좌/우/서브우퍼) 오디오 출력, 밸런스드
    3ch 출력 예: Main Out/2ch + Sub Out/1ch
  • 전원 공급: 콘센트 3구 (최소) / F 타입 플러그

영상 Projector

  • 프로젝터 * 2 — 비디오 입력 — 입력: WUXGA 1920 * 1200 (각각)

메인 PA 2ch Main PA 2ch

  • 좌(Left) 스피커 / 우(Right) 스피커 → 스피커로
  • 서브우퍼 스피커 → 서브우퍼로 (서브우퍼 스피커 수에 따라 다름)

* 스크린(각 5000 × 8000 mm)을 120° 각도의 V자 형태로 배치한 경우

* 스크린(각 5000 × 8000 mm)을 위아래로 쌓아 배치한 경우
